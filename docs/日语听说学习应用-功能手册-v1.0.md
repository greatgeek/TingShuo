## 1. 第一次使用：5 分钟上手

**第 1 步 登录**：打开应用，用邮箱密码登录。电脑和手机用同一个账号。

**第 2 步 告诉应用你的水平**：设置里选 N5 / N4 / N3。这决定了生成材料的难度——选错了也没关系，随时可以改。

**第 3 步 输入今天的词单**：把你今天想学的 20 个词粘贴进去（格式见第 2 节），点「提交并生成」。

**第 4 步 等约 1—3 分钟**：应用在生成 3 段对话、1 篇短文和全部句子的朗读音频。你可以离开页面，回来就好了。

**第 5 步 开始今天的学习**：按屏幕上方的 9 个步骤，从「盲听」开始一步步走。全程跟着界面提示即可，不需要任何教程。

**预期效果**：5 分钟后你已经在听今天的第一段对话了。之后每天只需做两件事：早上交词单，然后按步骤学习 30 分钟。

## 2. 每日词单：一天 20 个词怎么输

**是什么**：词单是每天学习的起点。你提供今天的生词，应用围绕它们生成对话和短文——所以材料永远在练「你今天要学的词」。

**什么时候用**：每天一次，建议固定在早上（通勤前）。

**怎么输**：三种方式任选。

1. **逐条输入**：一行一个词，格式 `单词｜读音｜词性｜中文`，用竖线隔开。不确定读音可以先空着，应用会补。

   ```
   精算｜せいさん｜名詞｜一起结账
   満員｜まんいん｜名詞｜满座、人满
   預ける｜あずける｜動詞｜寄存
   ```

2. **整段粘贴**：从课本、生词本、别的 App 里复制多行，一次性贴进大输入框。应用会逐行检查，格式不对的行会标红，改好那一行就能提交，其余不受影响。

3. **导入文件**：支持 CSV / TXT 文件（UTF-8 编码）。

**提交前检查**：重复的词自动去掉。解析成功的词会**列成清单**（读音、词性、中文、状态标签都看得见），提交前核对，点状态标签随时改。词数没有硬性要求——哪怕 1 个词也能生成一课；常规推荐每天 20 个（约 30 分钟的学习量）。

**词上的小标记**：每个词可以标 4 种状态——

| 标记 | 什么时候用 |
|---|---|
| 新词 | 默认状态 |
| 重点词 | 今天最想拿下、希望它在材料里出现两次的词 |
| 已掌握 | 已经很熟，不需要重点练 |
| 易错 | 老搞混的词，学习过程中发现随时改标 |

**遇到问题怎么办**：粘贴后大部分行标红？多半是分隔符不对——检查一下是不是用了中文全角竖线「｜」和竖线「|」混用，或空格代替了竖线。

**预期效果**：提交后每个新词都会出现在当天至少一句话里，重点词出现两遍——你不用再自己想「这个词怎么用」，材料替你安排好了。

## 3. 材料生成：提交之后发生了什么

**是什么**：提交词单后，应用会自动产出一套当天学习材料：3 段生活场景对话（每段 4—6 轮）、1 篇短文、5 个即问即答、5 个造句任务，并为**每一句话**单独生成朗读音频。

**生成要多久**：通常 1—3 分钟。进度页有两个进度条：第一个是「写材料」，第二个是「配朗读」。进度页可以离开，生成不会中断，回首页能看到完成状态。

**材料里都有什么**：

- 对话场景从你设置的主题里选（便利店、车站、午饭、约朋友、家、公司……），也可以每次手动指定；
- 所有汉字头顶都有假名注音，每句都带中文翻译；
- 难度贴合你设置的水平（N5/N4/N3），默认用です・ます体，对话里会适度混入自然口语；
- 「新词复现表」显示每个词出现在哪几句——如果某个词实在不适合当天场景，表里会说明原因，而不是硬塞一句不自然的日语。

**对材料不满意怎么办**：

- 不喜欢某一段对话：可以单独重生成这一段（应用内点该段右上角菜单）；
- 整体不对味：改设置里的水平或场景主题，第二天生效；当天重生成则使用新设置。

**生成失败了怎么办**：生成页会显示失败提示，点「重试」即可，不用重新输入词单。个别句子配不出音频也不影响学习——那句话先看文本，稍后点句子上的小刷新单独补。

**预期效果**：3 分钟后你拿到一套完全围绕今日词单、难度合适、每句都能点播放的听说材料，直接开课。

## 4. 听音频：播放控制一览

**是什么**：每一句话都有自己独立的音频和播放按钮——想反复听哪句就点哪句，不用拖进度条找位置。

**什么时候用**：学习全程（日课 9 步）、复习时，都会用到同一套播放控制。

**怎么用**：

- **单句播放**：点句子旁边的 ▶，再点一次重听。
- **单句循环**：长按句子选「循环」，这句会一直重复到你关掉。
- **AB 复读**：点第一句标 A、再点后面某句标 B，之间循环播放。
- **连播整段**：材料页点「整段连播」，从第一句播到最后。
- **盲听模式**：把文字全部藏起来，只听声音——屏幕上只有一排圆点，每播一句亮一个。

**语速**：三档可切——慢速 0.85x / 正常 / 稍快 1.15x。切到没生成过的档位，这句会现场补一个音频，几秒后自动播放。

**音色**：对话里两个角色用不同声音（一男一女），短文单独一个声音，设置里可以换。

**音频可以离线听**：当天课程打开过一次后，音频就存在本机了，之后地铁里、飞机上没网也能正常听（见第 9 节）。

**遇到问题怎么办**：某句点播放没声音——点句子上的小刷新按钮重试；仍不行就先看文本继续学习，稍后重试，别卡在这一句上。

**预期效果**：从「整篇一个 MP3 拖来拖去」变成「哪句不会点哪句」，重复听 10 遍一个词的成本是零。

## 5. 学习日课：9 个步骤详解

**是什么**：日课是应用内置的固定学习流程，9 个步骤从「听懂」到「说出口」层层递进。每步可以跳过、回退，中途退出不丢进度。

**什么时候用**：每天一次，建议拆成两段：白天做 1—4 步（约 15 分钟），晚上做 5—9 步（约 15 分钟）。

### 第 1 步 盲听

- **做什么**：不看文字，把对话/短文完整听 1—2 遍，抓大意和关键词。
- **怎么用**：点「开始盲听」，屏幕上没有任何文字，只有句子进度点。听完给自己评「听懂了几成」。
- **这个自评有什么用**：评得低的材料，里面的句子之后会优先进入你的复习队列。
- **预期效果**：先让耳朵接触新词，而不是先看字——这是听力的正确顺序。

### 第 2 步 看文本跟读

- **做什么**：逐句看文字听、出声跟读，每句 2—3 遍。
- **怎么用**：点任意一句播放，大字显示原文——汉字头顶有小假名注音（可一键隐藏，隐藏后就是纯自然日语文本；中文翻译默认隐藏，点「中译」按钮才显示）。卡壳的句子点「标记难点」，它自动进复习池。
- **预期效果**：把「听出来了」变成「嘴巴跟得上」。

### 第 3 步 影子跟读

- **做什么**：音频不停，跟着音频延迟半句同步说，像影子一样贴着音频。
- **怎么用**：点「开始」，整段连续播放，当前句滚动高亮。跟不上没关系，先跟上你能跟的。
- **预期效果**：训练语调和语速，这是口语流利度最重要的练习之一。

### 第 4 步 角色扮演

- **做什么**：选一个角色（A 或 B），对话轮到你时由你来说。
- **怎么用**：选角色后开始——对方的话自动播放（有声音），轮到你时屏幕显示文字但不出声，你来说。可以开着录音（见第 6 节）。
- **预期效果**：第一次「主动说」而不是「跟着说」，完成对话的实战感。

### 第 5 步 录音回放

- **做什么**：给自己觉得难的句子录音，和标准朗读交替对比。
- **怎么用**：选中句子 → 录 → 「听标准 → 听我的」两个按钮交替点。
- **预期效果**：耳朵对自己的发音是有滤镜的，录音不会骗人——差异一听便知。

### 第 6 步 复述

- **做什么**：合上文字，用自己的话把对话/短文说成 3—5 句，录音。
- **怎么用**：屏幕只给几个关键词卡片提示，说完展开原文对照。
- **预期效果**：从「能跟读」到「能组织语言」，这是输出能力的分水岭。

### 第 7 步 即问即答

- **做什么**：回答应用围绕材料出的 5 个口头问题。
- **怎么用**：先听问题（可以反复听）→ 出声回答（可录音）→ 展开看参考答案。
- **预期效果**：模拟真实对话里「被问—要答」的反应速度。

### 第 8 步 替换造句

- **做什么**：用重点词造和你自己生活相关的句子。
- **怎么用**：看中文提示 → 打字或说出你的句子 → 展开参考答案对比。
- **预期效果**：把课本场景的词迁移到你自己的日常，记得更牢。

### 第 9 步 标记难点（收尾）

- **做什么**：回顾本课标过的难点句，确认加入复习池，完成今日课程。
- **预期效果**：首页显示「今日已完成」，明天这些难点准时出现在复习列表里。

**预期效果（整节）**：约 30 分钟完成「输入 → 跟读 → 输出」的完整闭环，而不是听 30 分钟却什么都没练到。

## 6. 录音与发音对比

**是什么**：在跟读、角色扮演、复述、问答任何环节，你都可以录下自己的发音，并和标准朗读一句一句对照。

**什么时候用**：只要你想知道自己「说得像不像」。建议至少每天在第 5 步录 3—5 句。

**怎么用**：

- 句子旁的麦克风按钮，按住开始说，松开结束；也可以点击开始/点击结束；
- 录完立刻可选「听标准 → 听我的」交替播放；
- 每条录音都记着「是哪句、哪一步录的」，在句子详情里能看到历史录音列表；
- 不满意的录音可以删掉重录，录音无限次。

**录音存在哪**：录完自动保存到云端（你的账号里），手机和电脑都能回听。没网时先存在本机，联网后自动传上去，不会丢。

**遇到问题怎么办**：录出来没声音？检查系统/应用的麦克风权限（电脑在系统设置里，手机在应用权限里）。

**预期效果**：坚持每天对比几句话，两周左右能明显感觉到自己的语调开始「贴」上标准朗读。

> 第二阶段将增加**发音打分**：应用会对你的录音给出准确度、流利度反馈，低分句自动进复习。

## 7. 复习：让单词真正留在身体里

**是什么**：应用自动维护一个复习池，收录你的「难点句」——盲听自评低的、你手动标记的、复述时卡壳的句子，按记忆曲线在第 2、4、8 天…（答对间隔翻倍）准时端到你面前。

**什么时候用**：每天开日课**之前**，先清完复习列表（通常 5—10 分钟）。手机端会按时推送提醒。

**怎么用**：打开首页「待复习」进入，句子以下列 5 种形式出现：

1. **听音频选句子**：放一句音频，从 4 个句子里选出你听到的那句；
2. **听写填空**：句子挖掉今天学的目标词，听音频补出来；
3. **看中文说日语**：显示中文翻译，你出声说日语；
4. **看关键词复述**：只给 2—3 个词，复述整句；
5. **看词造句**：给一个词，口头造一个句子。

每题答完自评「过 / 没过」。**没过的句子明天再见，连续答对的句子间隔越来越长**，直到你标记「已掌握」让它毕业。

**复习能离线做**：已缓存课程的复习句子，断网也能照常复习。

**预期效果**：不用自己决定「该复习什么了」——打开就是今天到期的，做完就清空。一个词从「见过」到「张口就来」大约经过 3—5 次复习循环。

## 8. 历史课程与导出

**是什么**：每一天的课程（词单、对话、短文、音频、你的录音和练习记录）都永久保存，可以随时回看、重学、导出。

**什么时候用**：想回听某天的材料、重学一遍印象最深的对话、或者把资料带去别的软件。

**怎么用**：

- 首页进「历史课程」：按月份浏览，可按单词、场景搜索，可收藏；
- 对任意历史课程**重学日课**：步骤流程重来一遍，录音重新开始，练习记录继续累计；
- **导出**三种格式——
  - 文本（Markdown）：对话+短文+翻译，适合打印或放阅读器；
  - 音频包（zip）：当天全部句子 MP3，可以放任何播放器；
  - JSON：完整结构化数据，适合自己写脚本处理；
- 删除课程需二次确认，会连同该课音频和录音一起删除（不可恢复）。

**预期效果**：学习轨迹完整可回溯——三个月后翻出「刚好学会『精算』的那一天」只要几秒钟。

**我的词库**：录入过的所有词都收录在底部导航的「词库」里——按状态（新词 / 重点 / 易错 / 已掌握）筛选、直接搜索；点一个词，能看到它在你**所有课程里出现过的句子**，每句都能播放。复习里没过的词自动标成「易错」，学习过程中随手改的状态也全在这里。

**预期效果**：任何时候都能回答「这个词我学到哪一步了」——是在词库里躺着，还是已经在句子里活过几十遍。

## 9. 多设备同步与离线使用

**是什么**：电脑（Windows / macOS）和手机（Android）登录同一账号，课程、复习进度、学习记录自动保持一致。

**什么时候用**：典型场景——早上手机上提交词单，通勤听；中午电脑上继续跟读；晚上手机上复习。每台设备接着上次的进度。

**怎么用**：不需要任何操作。打开应用时自动同步（联网状态下）；进度、标记、复习状态以最新为准。

**离线怎么工作**：

- 当天课程**打开过一次**，材料和音频就缓存在本机——之后断网也能完整学习（含录音）；
- 断网时产生的学习记录、标记，联网后自动补传，不会丢；
- 手机端默认「仅 Wi-Fi 下载音频」，流量党可放心；想随时下载可在设置里改。

**遇到问题怎么办**：两台设备同时用，某句的难点标记似乎不一致？以最后操作的为准；刷新一次即可看到统一后的状态。

**预期效果**：换设备就像换房间——学习不中断，数据不分裂，不需要手动「传输」任何东西。

## 10. 设置项说明

每个设置项只解释你真正需要决定的事。

| 设置项 | 是什么 / 怎么选 |
|---|---|
| 日语水平 | 生成材料的难度。N5 能听懂大部分、N4 略有挑战、N3 明显吃力——选「略有挑战」的那档最利于进步。随时可改，下次生成生效 |
| 场景主题 | 想在对话里遇到的场景（便利店、车站、午饭、约朋友、家、公司…），多选。越贴近你的生活越好 |
| 语体 | 默认です・ます体 + 适度自然口语。如果你主要想练动漫腔/朋友间对话，选「偏口语」 |
| 默认音色 | 对话 A / B 角色和短文各用哪个声音。听腻了就换，句子会自动换配 |
| 默认语速 | 三档。建议跟读期用慢速，熟练后调正常 |
| 自动生成音频 | 默认开：材料生成完自动配全部音频。关掉则只生成文字，你听哪句再点哪句 |
| 学习提醒 | 每天固定时间推送「该学习了」（含今天待复习数） |
| 仅 Wi-Fi 下载 | 默认开（手机端）。关掉则流量也下载音频，一天约 2MB |
| 深色模式 | 跟随系统 / 亮 / 暗 |
| 缓存管理 | 查看音频、录音占了多少空间，一键清理 |
| 录音云同步 | 默认开：录音自动存到云端（你自己的服务器），换设备也能回听；不想留的录音随时删 |
| LLM 服务配置 | 第一次使用要填：服务商地址、API Key、模型名。**只存在本机**——不上传、不同步到别的设备、服务端数据库里根本没有它；填完点「测试连接」，通了就能用，换服务商随时改 |
| Azure 语音配置 | 填 Azure Speech 的 Key 和地域（如 japaneast）。**同样只存本机**；点「测试连接」会真的念一句日语给你听 |
| 数据导出与账号删除 | 导出全部学习数据（JSON/文本包）；删除账号前会引导你先导出 |

**预期效果**：设置一次、几乎不用再动——唯一建议常动的是「场景主题」，让它始终贴着你最近的生活。

## 11. 常见问题

**Q1：一天只能学一课吗？**
是。一天一个词单、一套材料，是刻意设计——学 20 个词并真正吃透，好过贪多。一天多课会在后续版本评估。

**Q2：词单必须 20 个吗？**
不是。没有硬性要求，1 个词也能生成一课；20 个是推荐量，学习时长约 30 分钟。

**Q3：读音（假名）不确定能不填吗？**
可以。生成材料时每个词都会给出注音，句子里的汉字也全部标注。

**Q4：音频为什么要等一会儿才好？**
每句话是单独生成、单独保存的——这是「哪句不会点哪句、无限重听」的基础。一次生成，之后永远秒开。

**Q5：为什么有的词没有出现在材料里？**
如果某个词实在不适合当天的场景（比如专有名词），应用会明说，而不是硬造一句奇怪的日语。可以让它明天再战，或换个场景主题重生成。

**Q6：复习列表里的句子是哪来的？**
三个来源：你标记的难点句、盲听自评低的句子、复述时卡壳的句子。都是「你实际没掌握」的证据。

**Q7：换手机/电脑，数据会丢吗？**
不会。登录同一账号，课程、复习进度、学习记录、**包括你的全部录音**都会自动恢复。

**Q8：没有网能用吗？**
当天课程打开过一次后：学习、录音、复习都离线可用。只有「提交新词单」「生成新材料」需要网络。

**Q9：我的录音会被上传到哪？**
上传到你自己的服务器（这个应用本来就是为你自己搭的），不经过任何第三方。不想保留的录音可以随时删。

**Q10：学英语/韩语吗？**
暂不支持，架构上已预留，会按「日语 → 韩语 → 英语」的顺序评估。

**Q11：我的 API Key 会被上传吗？**
不会。两个 Key（大模型、Azure）都只存在你填写的**这台设备**上——不上传、不同步、不备份到云端，服务器数据库里根本没有它们。代价是换设备要在新设备重新填一次。
